# AI Agent Glasses V0.1 — 机械验证样机

## 文件
- `exploded_assembly.step`：拆解装配 CAD，毫米单位，可用 FreeCAD / Fusion 360 导入。
- `01` 至 `09`：每个结构件都有 STEP（可编辑几何实体）和 STL（3D 打印）文件。
- `preview.scad`：OpenSCAD 拆解视图（彩色），需要与 STL 文件放在同一目录。
- `build.py`：CadQuery 生成脚本，可修改尺寸后重新生成。

## 设计坐标及假设
- 坐标单位 mm。X 横向，Y 前后，Z 上下。
- 眉梁宽 148 mm；镜腿长 115 mm；HUD 外壳约 54×19×18 mm。
- OLED 暂以 24×7 mm 空腔示意；实际模组外形、排线、接口位置**尚未确定**。
- HUD 光学框窗口约 22×19 mm，尚未进行视场、眼距、焦距和透光率设计。
- 仅预留滑动载架；**未设计驱动电机、传动机构、限位开关或电气自动收纳控制**。
- 未建真实镜片、鼻托软垫、转轴、螺纹嵌件和完整光学件。

## 打印建议
- PETG 或 PA12 作为机械试验材料；0.2 mm 层高；4 壁；35% 填充。
- 螺钉孔尺寸仅供验证，打印后需根据实际 M2/M2.5 紧固件修正。
- 与眼部接触部分必须增加圆角、软垫和防脱落结构。

## 下一步工程工作
1. 确认具体 OLED、准直透镜、半透镜的供应商图纸和实际尺寸。
2. 确定眼距、瞳距、佩戴空间、可见视场，建立真实光路模型。
3. 选择电机和丝杆/齿轮或滑轨结构，完成收纳行程和限位设计。
4. 修正公差、装配顺序、配重、线束、散热，再打印迭代。

**注意**：本模型是可导出实体的概念验证机械 CAD，并非可直接量产或安全佩戴的最终工程图。
