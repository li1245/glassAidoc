## 2. 需要你确认的事项

1. **D-010**：作业与会话 ID 以 PostgreSQL 为准、Hindsight 存带标签的语义记录，是否同意？
2. **D-016**：到期未确认的试用技能，暂停还是直接删除？
3. **D-017**：每设备同时一个作业是否合适？
4. **D-015**：默认单路、失败再并行，是否同意？
5. 试用期的长度（默认 7 天）与到期后是否通知用户。
6. 生物特征类技能第一次启用需用户明确同意，是否接受这个流程。

## 3. 已知的取舍

- 选择 RPC 子进程而不是进程内 SDK，多了一层进程通信，但换来隔离与独立升级。
- 选择 PG 为事实源，增加了几张表，但清理与恢复不再依赖语义检索。
- 选择默认单路生成，少了并行带来的成功率提升，但避免了不必要的成本；是否更优要用评测数据证明。
